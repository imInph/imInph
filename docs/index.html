inphub v4.1.0 · MIT
A dashboard I built for myself to keep my own stuff in one place: money, tasks, habits, goals, notes, focus sessions, my GitHub repos and a log of what I changed. It runs on my own machine, not on a server.
 
▸ ASP.NET Core on .NET 10 with minimal APIs. The SQL is written out by hand over plain ADO.NET, no Entity Framework, no Dapper.
▸ The frontend is TypeScript compiled to plain ES modules. No React, no bundler.
▸ It used to be PHP. v4.0 moved most of it to C# and v4.1 moved the rest.
▸ Widgets you drag around, k to search everything, an Insights tab with charts across sections.
▸ Optional AI chat through Claude, Ollama or LM Studio. Off by default, everything works without it.

inphner v1.2.0
A speedcubing timer and algorithm trainer. csTimer rebuilt with a calmer interface, clearer stats and a proper case trainer. Everything stays in your browser.
 
▸ Random-state scrambles for every WCA event, generated in a worker.
▸ WCA-correct averages that update in a few ms, even at 50 000 solves.

inph@inphserver:~$ cat projects/inphish/README
inphish v5.0.0 · GPL-3.0
A UCI chess engine in Rust. No board of its own: load it into any chess GUI and it talks UCI over stdin and stdout.
 
▸ Its own search: PVS, a transposition table, null-move, LMR, ProbCut, quiescence and Lazy SMP up to 256 threads.
▸ Evaluates with Stockfish 19's NNUE network, run by inphish's own inference code, which matches Stockfish's output exactly.
▸ Syzygy tablebases, Chess960, and an optional book of 6.4 million positions from 2000+ Lichess games.
▸ Every release plays matches against Stockfish. 5.0 scored 12.5 / 20 at its highest setting.

inph@inphserver:~$ cat projects/inphiso/README
inphiso
One Bash script that flashes Windows and Linux images to USB drives from Linux, including the parts that usually break.
 
▸ Splits install.wim into .swm chunks when it's over FAT32's 4 GiB limit, which is basically every Windows 11 ISO.
▸ Streams .xz, .gz, .bz2 and .zst images straight into dd. Nothing gets unpacked first.
▸ Works out if the image is Windows or Linux. If it can't tell, it asks.
▸ You type YES before it writes anything, and the system disk isn't even in the list.

inph@inphserver:~$ cat projects/inphex-monolyth/README
inphex-monolyth Tang Nano 9K
Three machines on a Sipeed Tang Nano 9K, in plain Verilog, built with yosys and nextpnr instead of the Gowin IDE. No downloaded CPU cores.
 
▸ cpu8, an 8-bit CPU with its own assembler that counts on screen over HDMI.
▸ doom, a 32-bit RISC-V core running a raycaster written in C.
▸ console, a RISC-V computer with an 80x30 HDMI text console and a bootloader that reads FAT32 off an SD card and runs whatever C program it finds.
▸ There's no framebuffer. 640x480 would need 300 KB and the chip has about 58 KB, so it stores characters and draws them while it scans.
▸ The font on this page is that console's font. Next up: an OS for it.
