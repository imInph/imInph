inph@inphserver:~$ cat projects/inphish/README
inphish v7.0.0 · GPL-3.0
A UCI chess engine in Rust. No board of its own: load it into any chess GUI and it talks UCI over stdin and stdout.
 
▸ Stockfish 19's search, ported onto inphish's own board and move generator: PVS, singular extensions, LMR, correction histories, Stockfish's time management and Lazy SMP up to 256 threads.
▸ Evaluates with Stockfish 19's NNUE network, run by inphish's own inference code, which matches Stockfish's output exactly.
▸ About 861,000 nodes per second on one thread of an Apple M2.
▸ Syzygy tablebases, Chess960, and an optional book of 6.4 million positions from 2000+ Lichess games.
▸ Every release plays matches against Stockfish. 7.0 scored 21/40 against 6.2.0 (6 W / 4 L / 30 D); 10.5/20 against Stockfish 19 at full strength

inph@inphserver:~$ cat projects/inphiso-gui/README
inphiso-gui v1.0.0 · GPL-3.0
Flash Windows and Linux images to USB drives, on Windows, macOS and Linux.
 
▸ Pick a local .iso / .img (plain or .xz / .gz / .bz2 / .zst), drop one on the window, or paste an HTTPS download link (downloads resume if interrupted).
▸ Checks the image's SHA-256 against a published checksum (SHA256SUMS, <file>.sha256, Fedora CHECKSUM files) found next to it, or one you paste.
▸ Lists removable drives only. The disk your system runs from is never listed, even with "Show all drives" on (it's traced through LVM and LUKS on Linux).
▸ Linux and hybrid ISOs, disk images: written byte for byte, decompressing on the fly.
▸ Windows installer ISOs: detected automatically, written as a FAT32 drive (MBR or GPT), with install.wim split into .swm parts when it's over 4 GiB. Windows Setup puts them back together by itself. MBR drives boot on both UEFI and legacy BIOS PCs, using inphiso's own boot code (crates/core/boot/).
▸ Verifies the drive by reading it back, then ejects it.
▸ Asks for your password (or UAC) only for the write itself. The app never runs as admin.

inph@inphserver:~$ cat projects/inphiso/README
inphiso
One Bash script that flashes Windows and Linux images to USB drives from Linux, including the parts that usually break. inphiso-gui is its desktop successor.
 
▸ Splits install.wim into .swm chunks when it's over FAT32's 4 GiB limit, which is basically every Windows 11 ISO.
▸ Streams .xz, .gz, .bz2 and .zst images straight into dd. Nothing gets unpacked first.
▸ Works out if the image is Windows or Linux. If it can't tell, it asks.
▸ You type YES before it writes anything, and the system disk isn't even in the list.

inph@inphserver:~$ cat projects/inphex-monolyth/README
inphex-monolyth Tang Nano 9K
Three machines on a Sipeed Tang Nano 9K, in plain Verilog, built with yosys and nextpnr instead of the Gowin IDE. No downloaded CPU cores.
 
▸ cpu8, an 8-bit CPU with its own assembler that counts on screen over HDMI.
▸ doom, a 32-bit RISC-V core running a raycaster written in C.
▸ console, a RISC-V computer with an 80x30 HDMI text console and a bootloader that reads FAT32 off an SD card and runs whatever C program it finds.
▸ There's no framebuffer. 640x480 would need 300 KB and the chip has about 58 KB, so it stores characters and draws them while it scans.
▸ The font on this page is that console's font. Next up: an OS for it.
